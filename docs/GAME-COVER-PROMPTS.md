# Game cover image prompts

Last reviewed: 28 July 2026.

Paste one block at a time into an AI image generator. Each block is written to
stand alone, so you do not need to carry context between them.

**Target size:** 1200x800 (3:2 landscape). Covers render with `object-contain`
since V2.15.2, so the whole image is always visible. Nothing important should
sit in the outer 5% on any edge.

**House style, applies to every prompt below:** flat vector editorial
illustration, bold geometric shapes, confident thick outlines, generous
negative space, no text or lettering anywhere in the image, no logos, no
brand marks, no recognisable real people, no small detail that disappears on a
phone. Each block already restates the essentials so you can paste it alone.

**Anything marked SOURCE MANUALLY** cannot be generated because it needs a
specific real reference. Find a licensed image and upload it by hand.

## SOURCE MANUALLY

These cannot be generated. Each needs a specific real reference, so find a
licensed image and upload it by hand.

- **Quiz: The Ultimate Harry Potter Quiz** — any generated cover either copies
  protected franchise artwork or looks like nothing. Use a licensed
  generic-magic stock image, or commission original art.
- **Quiz: Marvel: Heroes, Villains & Infinity** — same problem, stronger. Do not
  generate anything resembling the characters, costumes or logo.
- **Quiz: Screen Time (film and television)** — safe to generate a generic
  cinema cover (see the Film Taglines prompt above for the visual language), but
  if you want recognisable film references it has to be licensed.
- **Quiz: Bonjour, France!** — a generated cover is fine, but if you want a real
  Paris skyline rather than an invented one, source a licensed photo.
- **Any quest challenge that references a specific real painting, album cover or
  film poster** (Famous Painting, Conference-Room Album, Two-Team Movie Poster).
  The cover should show the *act of recreating* rather than the work itself. If
  you want the real work shown, it must be licensed.
- **Client-branded event covers** — always supplied by the client.
